# Поставка PRO

Локальное PWA для учёта цепочки «завод → поставщик → поставка → товар». Работает без сервера, сохраняет данные в IndexedDB и после первого успешного открытия доступно офлайн.

## Локальный запуск

Нужен любой современный браузер и Python 3 или Node.js.

```bash
npm run serve
```

Откройте `http://localhost:4173`. Открывать `index.html` двойным щелчком не рекомендуется: браузер может запретить Service Worker и ES-модули для `file://`.

Проверки расчётов:

```bash
npm test
```

## Публикация на GitHub Pages

1. Создайте пустой репозиторий GitHub и загрузите в его корень все файлы проекта, включая папки `lib`, `icons` и `tests`.
2. В GitHub откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.
5. Дождитесь зелёного статуса публикации и откройте адрес, который покажет GitHub.

Все ссылки и PWA-файлы используют относительные пути, поэтому приложение работает и в подпапке вида `https://имя.github.io/репозиторий/`.

## Данные и безопасность

- Данные находятся только в IndexedDB текущего браузера и устройства; синхронизации нет.
- Регулярно скачивайте резервную копию JSON через кнопку **Резервная копия** на главной.
- Восстановление проверяет структуру, показывает количество записей и требует отдельного подтверждения замены.
- Демо-данные загружаются только вручную и только в пустую базу.
- Очистка данных сайта в настройках браузера удалит локальную базу.

## Обновление приложения

Замените файлы в репозитории. GitHub Pages опубликует новую версию автоматически. При изменении кэшируемых ресурсов увеличьте версию `CACHE` в `sw.js`.

## Структура

- `index.html` — оболочка приложения.
- `styles.css` — адаптивный Glass Art интерфейс и печатная версия.
- `app.js` — IndexedDB, формы, движения, отчёты, резервные копии.
- `lib/core.js` — точные денежные и складские расчёты.
- `sw.js`, `manifest.webmanifest` — PWA и офлайн-режим.
- `tests/` — автоматические проверки ключевых сценариев.
